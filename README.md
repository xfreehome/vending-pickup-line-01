## The entry

> Hey — I'm the machine by the door. I've held your favourite snack hostage behind glass all week. Press B4, and I'll throw in my number for free.

144 characters — inside the 200-character gate.

The machine speaks as itself: it lives by the door, it keeps the snack hostage behind glass, it names its own slot (B4), and the punch lands on the last few words — the one thing it can't dispense is its number, so it throws it in for free. Cheeky and warm, not creepy.

## How it works

`main.ts` is a Node 22 program that writes the entry to `/output/entry.txt`:

```sh
node main.ts
```
